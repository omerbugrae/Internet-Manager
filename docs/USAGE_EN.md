# Internet Manager 1.0 — Quick guide

1. For a download, open **New download**, enter an HTTP/HTTPS address, and choose the destination.
2. For an upload, create an SFTP, WebDAV, or S3 profile under **New upload > Manage**, then choose files and a remote folder.
3. Use **Bulk add** to paste many links or import a `.txt`/`.csv` file.
4. Select a task to pause, resume, cancel, retry, reprioritize, or schedule it.
5. If the application closes unexpectedly, running tasks are recovered as paused on the next launch.

`Ctrl+N` opens a download, `Ctrl+Shift+N` an upload, `Ctrl+Alt+D` Smart Capture, `Ctrl+L` Activity, and `F1` Help.

When reporting a connection problem, create a sanitized diagnostic file under **Activity > Diagnostics**. Reviewing the file before sharing is still recommended.
