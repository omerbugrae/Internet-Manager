# Changelog

## 1.0.0 — 2026-09-12

- First stable Windows 10/11 release.
- HTTP/HTTPS downloads with pause, resume, parallel ranges, queueing, priorities, and bandwidth limits.
- SFTP, WebDAV, and S3-compatible uploads, including resumable S3 multipart sessions.
- Bulk import, drag-and-drop, Smart Capture, scheduling, tray operation, notifications, and recovery after interruption.
- Windows secure credential storage, database migrations, diagnostic export, sensitive-log redaction, proxy/TLS controls, and hardened Electron content policy.
- Guided NSIS installer and signed GitHub stable-update pipeline.

## 0.9.0 — 2026-09-12

- Release-candidate hardening, migration framework, diagnostics, proxy/TLS controls, updater foundation, and packaging preparation.
