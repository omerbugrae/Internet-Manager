# Privacy

## Türkçe

Internet Manager hesap gerektirmez; analiz veya reklam sistemi içermez. Transfer adresleri, yerel yollar, görev geçmişi, ayarlar ve şifrelenmiş bağlantı profilleri kullanıcı açıkça profil ya da tanılama dosyası dışa aktarmadıkça bilgisayarda kalır.

Parolalar ve gizli anahtarlar Windows güvenli depolamasıyla şifrelenir. Profil dışa aktarımı parolaları, gizli anahtarları ve oturum token'larını içermez. Tanılama dosyaları kimlik bilgisi alanlarını, yetkilendirme değerlerini, imzalı URL parametrelerini ve proxy kimlik bilgilerini temizler.

Uygulama yalnızca kullanıcının belirlediği hedeflere ve güncelleme denetimi için yapılandırılmış GitHub sürüm adresine bağlanır. Uzak sunucular ve ağ aracıları kendi politikalarına göre bağlantı bilgisi kaydedebilir.

Aktivite günlüğü uygulamadan temizlenebilir. Kaldırma işlemi, yarım transferleri ve ayarları kaybetmemek için uygulama verilerini varsayılan olarak korur.

## English

Internet Manager does not require an account and does not include analytics or advertising. Transfer addresses, local paths, task history, settings, and encrypted connection profiles remain on the user's computer unless the user explicitly exports a profile or diagnostic file.

Passwords and secret keys are encrypted with the Windows secure-storage service. Exported profiles omit passwords, secret keys, and session tokens. Diagnostic exports redact credential fields, authorization values, signed URL parameters, and proxy credentials.

The application connects only to destinations requested by the user and to the configured GitHub release endpoint when checking for updates. Remote servers and network intermediaries may independently record connection metadata according to their own policies.

Users can clear the activity log from the application. Uninstalling preserves application data by default so interrupted transfers and settings are not lost.
